## 命令

在隔离 Android 目录执行；Shared 根名取 Gradle `projects` 的实际配置，而不是假设存在根 `clean` task。

```bash
export JAVA_HOME=/Users/daubert/.gradle/jdks/eclipse_adoptium-21-aarch64-os_x.2/jdk-21.0.7+6/Contents/Home
export ANDROID_HOME=/Users/daubert/Library/Android/sdk
shared=/private/tmp/ugreen-android-architecture-20260914/shared-release-1.7.0-9q2u2wrq
./gradlew projects --no-daemon --console=plain -PugreenHomeSharedPath="$shared" -PfirebaseCrashlyticsMappingUpload=false
./gradlew clean :app:assembleDomesticDebug --no-build-cache --no-daemon --console=plain -PugreenHomeSharedPath="$shared" -PfirebaseCrashlyticsMappingUpload=false
# 仅隔离业务文件临时添加顶层私有 marker 函数；先保留原始字节，完成后还原。
./gradlew :app:assembleDomesticDebug --no-build-cache --no-daemon --console=plain -PugreenHomeSharedPath="$shared" -PfirebaseCrashlyticsMappingUpload=false
./gradlew :app:testDomesticDebugUnitTest testDebugUnitTest --continue --no-daemon --console=plain -PugreenHomeSharedPath="$shared" -PfirebaseCrashlyticsMappingUpload=false
cd "$shared"
../android/gradlew :core-util:jvmTest --no-daemon --console=plain -PugreenHomeSharedPath="$shared" -PfirebaseCrashlyticsMappingUpload=false
```

计时实际使用 Python `time.monotonic()` 包裹 Gradle 子进程；配置检查与首次装配使用 `/usr/bin/time -p`。完整参数、退出码见[构建结果](构建结果.json)与[首次验证结果](首次验证结果.json)。该阶段仅构建、不安装；后续离线模拟器验证见末节。未发布，不访问用户 IoT 设备。
