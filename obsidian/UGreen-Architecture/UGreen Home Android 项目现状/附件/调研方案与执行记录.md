## 调研与验证口径

- 源码范围以 Android 主工程实际 Gradle module、source set、Git submodule 和生效的 Composite Build 映射为准；同时记录 Shared 的 Android 相关边界。RN 独立源码仓库和其他平台不自动纳入全仓审计。
- Shared 接入现状：主工程 `gradle.properties:28-29` 显式配置 `ugreenHomeSharedPath=../UgreenHome-Shared` 并启用 Composite Build，但该平级目录当前不存在。Shared 并非 Android 仓库的 Git 子模块；不能将路径声明当作已存在的 checkout。
- 用户指定的临时验证来源：`/Users/daubert/UGreen/ugreenhome/ugreenhome-shared`，即 iOS 仓库的 Shared 子模块。复核时 HEAD 为 `96785f44747753468fc18a8b07405f695cbfbebb`，其 `ugreenhome-strings` 存在未跟踪内容提示；执行前重新记录实际版本、子模块状态和工作区差异，不清理已有内容。
- 实测复制 Android 与上述 Shared 到隔离目录，仅在隔离 Android 工程临时覆盖 `ugreenHomeSharedPath`，使其指向从 iOS 子模块取得的 Shared 副本（优先使用 Gradle `-PugreenHomeSharedPath=<隔离 Shared 路径>`）。不直接在 iOS Shared checkout 内执行构建，也不修改 Android 原配置。确认资源路径和 Composite Build 均使用此替换值。
- 分别记录“Android 原配置的缺失路径”和“借用指定 Shared 版本后的集成验证”。后者即使通过，也不证明原配置可直接构建，或该 Shared 版本就是 Android 原计划配套版本；API/版本兼容问题按实际结果记录，不擅自切换 Shared 分支或升级依赖。
- 共用内容去重：对照 iOS 现状笔记的源码快照，核实仍适用后通过相对链接引用共享模块职责、通用实现和已有说明，不重复展开。Android 文档保留 Android source set、依赖替换、平台实现、宿主调用/状态边界、版本差异及本轮实际构建/测试证据；历史 iOS 测试通过记录不能代替 Android 验证。
- Android 仍有独立的 `ugreen-media` Git 子模块，与 Shared 的接入方式不同。最新复核已初始化，HEAD 为 `0ffe35a3c02dfa5f0b9d21fcece3e7725f7c1d0e`，取代先前“未初始化”的记录。执行前再检查所有所需源码及版本，不切换原仓库分支。
- 声明依赖与运行时调用分开记录；目录存在、依赖声明或测试文件数量不等于线上可达或执行通过。
- 在 `/private/tmp` 建立隔离副本执行 Gradle 命令，避免修改当前工作区；不执行依赖升级、发布、上传或清理用户缓存。
- 检查 flavor、签名及上传脚本后选择主 App 的一个可用 Debug variant，明确其产品范围。先尝试 clean 构建；成功后在同一副本和缓存下修改一个业务源码文件，再测增量构建，确认编译任务实际执行并还原变更。失败耗时不计入成功基线；基线构建未通过时不制造增量成功数据。依赖准备耗时单列，缓存命中边界如实记录。
- 清点 unit/integration/UI 测试资产，并实际执行可安全运行的 JVM/Android unit test；设备测试先检查可用设备、测试宿主与外部副作用，不默认启动真实业务会话或连接用户 IoT 设备。分别记录案例数、失败、跳过及覆盖率可用性；无报告不推断覆盖率。所有失败保留命令、退出码、耗时和阻断原因，不为追求通过擅自修复业务源码。
- 记录 Gradle/JDK/Android SDK/设备或模拟器、源码 HEAD、Shared HEAD 与工作区状态；不把单次耗时描述为稳定基线。
- 不实施产品代码重构，不修改依赖锁定，不提交 Android 源工程改动；本设计按 brainstorming 流程单独提交，后续产物不自动提交或推送。不复制或记录签名私钥、口令、令牌；私仓认证或网络权限受阻时走受支持的审批路径。

## 验收标准

1. 九篇正文与 iOS 目录同名维度可互相导航。
2. 关键结论具有相对源码路径和行号；不以历史设计文档替代当前证据。
3. 构建/测试章节明确成功、失败、未执行和隔离范围。
4. 附件中的命令、快照和摘要可复核，敏感信息已避免写入。
5. Android 源工程、iOS Shared 及涉及子模块的工作区状态与执行前一致；既有修改保留，临时路径替换和构建产物仅在隔离副本中产生。
