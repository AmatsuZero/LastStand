## 2. 主要结论

| 当前结论 | 证据 / 边界 |
|---|---|
| Android 是 Native + KMP/Compose + RN 宿主的混合工程，Compose root 回注 Android Fragment；不能将旧 MainFragment 当作默认启动根 | 高：Manifest、Splash、RootActivity 与 Shared root 接入源码，见 01/05 |
| 主工程与 Shared 必须同名分支；本轮以两个 `release/1.7.0` 固定提交验证 | 高：Android `README.md:75-85`、同分支 projects 通过；不保证任意同名提交都兼容 |
| 原 `../UgreenHome-Shared` 路径缺失；借用 iOS 对象库导出的匹配分支能完成 Android 构建 | 高：文件系统检查与隔离构建，未回写原路径 |
| Room/会话/设备 runtime/RN KV 等有不同 owner 和清理边界，不是单一全局 store | 高：静态读写/退出回调，详见04；不代表真实账号/设备联调验证 |
| domesticDebug Clean **103.89 秒**，单文件增量 **33.24 秒**均通过 | 高：退出0、编译任务和未签名APK；临时签名副本另完成 API36 模拟器安装/启动冒烟；单次样本，复用用户缓存 |
| Android 本地单测 **216 个：214通过、2失败**；Shared core-util JVM **37个全部通过** | 高：JUnit套件和逐案例摘要；不外推到未运行的 Shared host/device 或真机测试 |

补充验证：依赖解析 **8/8 成功**（Bugly实际选中4.1.9.3，Ktor core3.1.0→3.5.1等，见03）；App instrumentation **3个：1通过、2初始化失败**；API36离线启动显示隐私协议页，未同意协议或登录，见[Android运行实测](附件/Android运行实测.md)。测试任务枚举已执行，覆盖率报告未取得。
