## 2. 主要结论

| 优先阅读 | 当前判断 | 置信度 / 证据性质 |
|---|---|---|
| 1 | 主 App 是 **UIKit Native + KMP/Compose + RN 宿主**的混合工程，不是已全量迁移的单一技术栈 | 高；root factory、原生 slot、认证/OTA bridge、RN 宿主调用证据 |
| 2 | 当前主窗口使用 KMP Shared root，由原生 coordinator 提供 Home、事件、UserCenter 等宿主；旧原生 Tab 类仍存在 | 高；`UGRootViewManager` 与 `UGSharedRootCoordinator` 实际安装代码，不以目录名判断 |
| 3 | Native 设备首页依赖 DeviceRelation 快照、RTCX manager、HomeViewModel 与 WCDB；不能替换描述为 KMM `domain-device` 已拥有全部设备状态 | 高；真实刷新、订阅和缓存链。KMM 同名 repository 需按包路径区分 |
| 4 | Network/Storage/Navigation 均跨技术栈协作：RN 网络桥明确复用 KMP；原生 Moya/Alamofire 仍存在 | 高；实际调用链。没有把所有 SDK 声明视为线上使用 |
| 5 | 用户更新 Pods 后复测通过：Clean Build 243.35 秒，单业务文件变更增量构建 44.30 秒；首次缺失 UHKit 文件的失败已成为历史记录 | 高；两次 Xcode 最终成功、退出码 0，增量日志确认业务文件重编译；各为单次样本 |
| 6 | 存在多层测试资产，但本轮只验证了独立子集；不能报告整个 App 测试通过或覆盖率 | 高；Xcode target、静态清单、Swift/JUnit/Node/unittest 输出 |

## 3. 覆盖范围与非目标

| 范围 | 处理方式 |
|---|---|
| `iot` 主 App | 业务功能、基础设施、启动、路由、状态、桥接、测试与构建入口 |
| NotificationService | 扩展 Target 与宿主嵌入关系；不当作主 App 内部页面 |
| `LocalPods` | 全部自有模块的职责和接入；只剩构建缓存的目录单独标注 |
| `ugreenhome-shared` | 当前检出的全部 Gradle module、源码边界、导出与平台实现；sample/test/tool 模块单独区分 |
| RN | 当前 iOS 仓库的宿主、bridge、runtime 契约与嵌入 bundle；没有把 bundle 当成可审计 JS 源码 |
| CocoaPods / SPM / Gradle | 锁定/声明版本、依赖方向与本地路径；未对每个第三方库做源码或许可证专项审计 |
| `Tools` | 与资源、国际化、RN 打包相关的工程工具与其测试 |
| 仓库外 Android/RN 独立项目 | 本次不另行审计兄弟仓库；只覆盖指定仓库中的 Android source sets、sample 和跨端契约 |

“全量”指指定工程内的模块与功能面全覆盖，不代表逐行审查第三方、实测每个产品功能、运行所有平台构建或访问真实用户环境。

本轮不实施重构、不调整 SDK 版本、不修复已有测试/编译问题、不发布或上传，不修改源项目业务代码，不提交 Git。Known Pain Points 依用户要求保持空白；构建和测试阻断仅用于说明验证范围。

## 6. 证据阅读规则

- **源码证据：** 声明、调用、状态写入或清理代码可定位。描述的是代码行为，不自动等同于所有场景运行正确。
- **实测证据：** 本次运行的最终退出状态、耗时和测试报告；环境错误与代码/断言失败分开。
- **推断：** 由多项证据得出的架构判断，明确推断范围。
- **未验证：** 缺少宿主调用、完整构建、设备/账号环境或覆盖率报告。保留限制，不制造完成结论。
