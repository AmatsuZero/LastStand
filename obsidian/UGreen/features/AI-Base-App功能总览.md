# AI-Base App 功能总览

来源：`AI-Base Pro APP需求文档`（App 应用层 + 同文档「端侧显示屏」）。

## App 功能列表

1. **设备配网**
   - AI Base Pro 配网添加
   - 未绑定的 IPC 添加到 AI Base Pro
   - 已绑定的 IPC 添加到 AI Base Pro
2. **设备卡片**
3. **设备详情**（含离线、解绑）
4. **存储管理**
5. **设备设置**（子账号、设备在/离线功能显示）
6. **智能化**
7. **Matter 设备接入 AI Base**
