# App研发新人学习知识库首页

## 页面与模块

单页中按顺序展示：

1. 欢迎语与知识库用途。
2. “认识团队成员”表格：姓名、岗位、个人说明书入口。
3. “新人任务”区：新人 landing 任务清单。
4. “必读资料”区：新员工入职须知、IT 指南、行政问答、员工手册和核心相关方清单。
5. “常用文档”区：按部门文档、项目文档等使用场景提供入口。

## 关键交互

- 点击成员的个人说明书链接，打开对应成员文档。
- 勾选 landing 任务，记录当前完成状态。
- 点击必读资料标题，打开对应制度或指南。
- 点击常用文档链接，跳转到知识库、看板、需求或设计稿。
