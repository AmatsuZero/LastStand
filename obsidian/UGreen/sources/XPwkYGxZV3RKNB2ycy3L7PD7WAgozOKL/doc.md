# **APP应用层需求描述**

## **设备配网**

作为一个用户我想： 通过手机连接我购买的AI Base Pro并进行配网添加

解决我：摄像头的录像存储到AI Base Pro上，并使用AI B   ase Pro上的AI 功能



**前置说明**
- AI Base pro连接网络后，会发出WiFi，且只可在绿联的设备扫描到，电脑手机扫描不出
- IPC需连接到AI Base发出的WiFi或与同一局域网下有线添加，只支持局域网添加
- AI Base添加设备，目前只使用所有的IPC

| 描述 | 操作 |
