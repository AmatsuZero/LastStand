# 学习笔记说明

`Notes/` 保存个人理解、问题、总结和跨文章连接，并由 Git 跟踪。新建笔记时使用 [[Templates/学习笔记|学习笔记模板]]。

- `status`：使用 `seed`、`growing` 或 `evergreen`。
- `topics`：描述知识主题，可填写多个值。
- `source_notes`：链接到 `Library/` 中的来源文章。
- `tags`：用于跨主题检索；建议使用稳定、简短的层级标签。

所有笔记可在 [[Views/学习笔记.base|学习笔记视图]] 中查看。
